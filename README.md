# Azure Account & GitHub Setup

## Overview
This project documents the initial setup of an Azure account and GitHub workflow used for Azure practical work.

## Objectives
- Create/activate an Azure for Students or free Azure account.
- Access the Azure Portal.
- Verify the Azure subscription.
- Prepare GitHub repositories for documenting cloud practicals.
- Organize screenshots and documentation for each project.

## Azure / Tools Used
- Microsoft Azure Portal
- Azure for Students / Free subscription
- GitHub
- Web browser

## Workflow
```text
Azure Account
     ↓
Azure Portal
     ↓
Verify Subscription
     ↓
Create GitHub Repository
     ↓
Document Azure Practical
     ↓
Upload README + Screenshots
```
